一、产品介绍
1.1 醒我APP
中文名：醒我
英文名：Remind Me
slogan：醒我，提醒你的每一刻。
需求：
在快节奏的生活中，人们常常会因为忘记重要日期或任务而感到焦虑。无论你是学生、职场人士、家庭用户，都有对时间管理的强烈需求。"醒我"APP旨在通过简洁直观的界面和强大的提醒功能，帮助用户高效管理时间，不错过任何重要事件。
设计风格：
极简风，功能操作简单，图标样式简洁大方但不缺乏设计美感。界面设计注重用户体验，力求以最少的步骤完成操作，同时保持视觉上的舒适感。
1.2 用户画像
1.2.1 学生群体
- 基本信息：
  - 年龄：12-25岁
  - 身份：中学生、大学生、研究生
  - 使用设备：智能手机、平板电脑、笔记本电脑
  - 使用场景：学校、宿舍、家中、图书馆
- 核心需求：
  - 倒数日/正数日
    - 考试日期倒数日：期末考、高考、四六级、考研、考公等。
    - 作业截止日期提醒：长期作业、阶段性任务的提醒。
    - 生日/纪念日提醒：记录同学、朋友的生日和有意义的纪念日。
  - 日历
    - 展示倒数日/正数日事项。
    - 课程表同步：提醒上课时间、作业提交时间。
  - 倒计时
    - 考试模拟倒计时：支持多科目、多类型的倒计时管理（如听力、写作、答题等）。
    - 学习时间管理：通过番茄钟或倒计时功能，帮助学生专注学习。
    - 运动计时：记录平板支撑等倒计时运动的时间。
  - 秒表
    - 运动计时：记录跑步等正计时运动的时间，支持分段计次。
- 行为特征：
  - 使用频率高，尤其是在考试季。
  - 偏好简洁、美观的界面，操作简单。
  - 对提醒的及时性和准确性要求高。
  - 喜欢个性化设置（如主题颜色、背景图片、提醒铃声）。
  - 可能喜欢分享学习进度、考试倒计时等（社交分享需求）。
- 痛点：
  - 容易分心，需要工具帮助专注学习。
  - 考试和作业任务多，容易忘记重要日期。
- 目标：
  - 提高学习效率，合理安排时间。
  - 不错过重要考试和作业截止日期。
- 功能优先级：
  - 倒数日/正数日功能（考试倒计时、作业截止提醒）。
  - 番茄钟/倒计时功能（学习时间管理）。
1.2.2 职场人士
- 基本信息：
  - 年龄：25-45岁
  - 身份：白领、管理者、自由职业者
  - 使用设备：智能手机、笔记本电脑、智能手表
  - 使用场景：办公室、出差、居家办公
- 核心需求：
  - 倒数日/正数日
    - 项目截止提醒：支持多项目、多任务的截止日期提醒。
    - 会议提醒：与日历同步，提醒会议时间和地点。
  - 日历
    - 任务优先级管理：支持任务优先级设置，帮助管理多任务。
    - 出差提醒：提醒航班信息、酒店预订等。
  - 倒计时
    - 工作专注计时：通过番茄钟功能提高工作效率。
    - 运动计时：记录仰卧起坐、平板支撑等倒计时运动的时间。
  - 秒表
    - 运动计时：记录跑步、骑行等正计时运动的时间，支持分段计次。
- 行为特征：
  - 使用场景多样化，包括办公室、出差、居家办公等。
  - 多设备同步，可能需要在手机、平板、电脑等多设备上同步使用。
  - 偏好高效、专业的设计风格。
- 痛点：
  - 任务繁多，容易遗漏重要事项。
  - 会议和出差安排复杂，需要高效的提醒功能。
  - 缺乏专注时间，容易被琐事打断。
- 目标：
  - 提高工作效率，合理安排任务优先级。
  - 不错过重要会议和项目截止日期。
- 功能优先级：
  - 倒数日/正数日功能（项目截止提醒）。
  - 日历同步功能（会议提醒）。
  - 跨平台同步功能。
  - 时间轴功能（规划中）。
1.2.3 家庭用户
- 基本信息：
  - 年龄：25-60岁
  - 身份：父母、子女、家庭成员
  - 使用设备：智能手机、平板电脑、智能音箱
  - 使用场景：家中、外出
- 核心需求：
  - 倒数日/正数日
    - 生日/纪念日提醒：支持家庭成员生日、纪念日的提醒，并提供礼物建议。
    - 家庭日程管理：支持多人共享日程，提醒家庭活动（如家长会、家庭聚会）。
    - 财务提醒：提醒水电房租话费等账单支付。
    - 健康管理：提醒家庭成员的健康检查、服药时间等。
    - 食材提醒：食材保质期提醒。购买食材提醒。
  - 倒计时
    - 烹饪提醒：多步骤计时（如煮饭、炖汤、烘焙等）。
  - 秒表
    - 运动计时：记录跑步、骑行等正计时运动的时间，支持分段计次。
- 行为特征：
  - 使用场景多为家庭内部，偏好温馨、友好的设计风格。
  - 偏好简单、直观的操作，需要简单易用的功能。
- 痛点：
  - 家庭事务繁杂，容易忘记重要日期（如生日、纪念日）。
  - 健康管理需求高，但缺乏系统化的提醒工具。
- 目标：
  - 不错过家庭重要日期和活动。
  - 通过健康管理功能关注家庭成员的健康状况。
- 功能优先级：
  - 倒数日/正数日功能（生日/纪念日提醒）。
  - 健康管理提醒（服药、体检提醒）。
1.2.4 健身爱好者
- 基本信息：
  - 年龄：18-40岁
  - 身份：健身爱好者、运动达人
  - 使用设备：智能手机、智能手表、健身手环
  - 使用场景：健身房、户外运动、家中
- 核心需求：
  - 倒数日/正数日：
    - 健身目标倒数日：提醒健身目标达成时间（如减脂目标、马拉松比赛日）。
    - 健身坚持正数日
  - 倒计时：
    - 运动计时：记录力量训练、瑜伽等运动的倒计时。
    - 休息计时：记录组间休息时间。
  - 秒表：
    - 运动计时：记录跑步、骑行等正计时运动的时间，支持分段计次。
- 行为特征：
  - 偏好激励性设计（如打卡、成就系统）。
  - 需要与可穿戴设备（如智能手表、健身手环）集成。
  - 喜欢记录运动数据并进行分析。
- 痛点：
  - 缺乏系统的运动计时工具，难以精确控制训练时间。
  - 需要手动记录运动数据，操作繁琐。
- 目标：
  - 通过精确的计时功能提高训练效率。
  - 通过记录运动数据跟踪健身进度。
- 功能优先级：
  1. 倒计时功能（运动计时、休息计时）。
  2. 秒表功能（运动计时）。
  3. 倒数日/正数日功能（健身目标倒数日）。

二、功能需求
2.1 核心功能
2.1.1 倒数日/正数日
功能名称：倒数日/正数日管理
功能描述：用户可以管理倒数日和正数日事件，便于追踪重要日期。
优先级：高
功能细节：
1. 列表视图功能
  - 导航切换
    - 顶部导航栏可切换倒数日、正数日和日历
  - 事件展示
    - 重要事件置顶显示，最多支持3个事件轮播
    - 进度条可选显示，展示事件进展百分比
    - 每个事件可设置1个分类，最多3个标签
    - 支持多时间单位视图切换（年、月、周、天）
  - 列表交互
    - 左滑：进入时间线记录
    - 右滑：编辑、复制、删除
    - 长按：拖拽排序
    - 单击：打开事件详情页面
    - 双击：切换显示数字和时间单位
  - 列表规则
    - 置顶规则：最多可置顶1个事件
    - 排序规则：默认按创建时间排序，还可按事件时间差值排列。
    - 分类规则：最多支持1级分类，限8个
    - 标签规则：每个事件最多可添加1个标签
2. 事件管理功能
  - 基础管理
    - 新增/编辑事件内容（标题限制20字）
    - 设置目标时间（支持重复周期）
    - 设置事件分类（最多8个分类） 
  - 提醒配置
    - 支持多个时间点提醒
    - 提醒方式：横幅通知、锁屏通知
    - 可设置提前提醒时间（5分钟~7天）
  - 扩展功能
    - 时间线记录（每个事件最多保存20条记录）
    - 小组件配置（最多支持3个桌面小组件）
异常处理：
- 无数据时显示引导页
- 网络异常时支持本地缓存
- 数据同步冲突时以服务端为准

2.1.2 日历功能
功能名称：日历管理
功能描述：用户可以在日历视图查看所有倒数日/正数日事件。
优先级：中
功能细节：
1. 日历视图功能
  - 基础展示
    - 支持月视图、周视图切换
    - 显示农历和节假日信息
    - 支持系统日历同步
  - 事件展示
    - 显示倒数日/正数日事件标记
    - 每日事件数量角标提示
    - 重要事件突出显示
  - 日历交互
    - 左右滑动：切换月份/周次
    - 点击日期：展开当日事件列表
    - 长按日期：快速创建事件
  - 展示规则
    - 每日最多显示3个事件预览
    - 超出显示"+n"提示
    - 事件显示优先级：置顶 > 重要性 > 创建时间
2. 事件管理功能
  - 查看功能
    - 支持日视图、待办列表切换
    - 支持事件筛选和搜索
    - 支持时间段选择
  - 同步配置
    - 支持系统日历读取权限配置
    - 支持订阅第三方日历
    - 支持导出日历数据（格式：.ics）
异常处理：
- 无数据时显示空状态日历
- 同步失败时提示重试
- 权限受限时引导开启

2.1.3 倒计时
功能名称：倒计时管理
功能描述：用户可以设置倒计时，用于精确计时的场景。
优先级：高
功能细节：
1. 计时功能
  - 基础功能
    - 支持时分秒设置
    - 支持暂停/继续/重置
    - 支持后台运行计时
    - 最大支持99小时59分59秒
  - 显示方式
    - 支持数字/圆盘样式切换
    - 支持进度条显示
    - 支持自定义背景
  - 提醒方式
    - 震动提醒
    - 声音提醒（可选铃声）
    - 通知提醒（横幅/锁屏）
  - 使用规则
    - 计时精度误差不超过1秒/天
    - 支持快速设置常用时长
2. 场景管理
  - 场景配置
    - 支持场景分类（学习、运动等）
    - 每个场景可保存5个预设时间
    - 同时最多运行8个倒计时
    - 支持场景重命名和删除
  - 历史记录
    - 记录最近50次使用记录
    - 支持记录导出
    - 支持记录分析统计
异常处理：
- 后台限制时提示用户
- 系统时间变更时重新校准
- 来电等打断时暂停计时

2.1.4 秒表
功能名称：秒表管理
功能描述：用户可以使用秒表，完成精确计次的场景。
优先级：高
功能细节：
1. 计时功能
  - 基础功能
    - 支持启动/暂停/复位
    - 支持分段计时
    - 支持后台运行计时
    - 计时上限99小时59分59秒99
  - 显示方式
    - 支持数字/圆盘样式切换
    - 支持分段记录列表
    - 支持最快/最慢圈速标记
  - 计次功能
    - 支持手动分段计次
    - 显示分段用时和总计时
    - 支持计次间隔分析
  - 使用规则
    - 同时最多运行2个秒表
    - 每个秒表最多记录99圈
    - 计时精度0.01秒
2. 记录管理
  - 数据记录
    - 自动保存最近30次记录
    - 支持记录命名和标签
    - 支持记录分享导出
  - 数据分析
    - 支持圈速统计分析
    - 支持最佳圈速比较
    - 支持数据图表展示
异常处理：
- 后台限制时提示用户
- 内存不足时自动清理旧记录
- 来电等打断时暂停计时

2.1.5 通知提醒
功能名称：通知提醒管理
功能描述：提供通知功能，用于提醒用户事件完成。
优先级：高
功能细节：
1. 通知功能
  - 提醒方式
    - 横幅通知（可配置显示时长）
    - 锁屏通知（支持直接操作）
    - 声音提醒（可自定义铃声）
    - 震动提醒（可自定义震动模式）
  - 重复规则
    - 支持单次提醒
    - 支持重复周期（每天/周/月/年）
    - 支持自定义重复（指定日期）
    - 最多支持10个重复规则
  - 通知样式
    - 支持简洁/详细两种样式
    - 支持快捷操作按钮
    - 支持直接回复功能
  - 使用规则
    - 单个事件最多设置5个提醒时间点
    - 提醒时间范围：5分钟~7天
    - 同时最多显示10条通知
    - 点击通知回到事件列表
2. 通知管理
  - 通知设置
    - 支持分类管理通知
    - 支持通知优先级设置
    - 支持免打扰时段设置
异常处理：
- 系统通知权限关闭时引导开启
- 免打扰模式下按规则处理
- 通知发送失败时重试

三、非功能需求
3.1 性能需求
- 响应时间：核心功能（如倒计时、通知提醒）的响应时间不超过1秒，确保用户体验流畅。
- 资源占用：优化本地存储和网络请求的资源占用，确保应用在低端设备上也能流畅运行。
- 并发支持：虽然大部分功能是本地化的，但在以下场景中可能涉及并发：
  - 云端数据同步：当多个设备同时进行数据同步时，需要支持并发请求。
  - 会员服务：当多个用户同时进行订阅或购买时，需要支持并发交易。
3.2 安全需求
- 数据加密：
  - 本地数据加密：对本地存储的敏感数据（如提醒内容、用户设置）进行加密。
  - 云端数据加密：使用云服务提供商的加密功能（如阿里云的KMS服务）对云端数据进行加密。
- 权限管理：
  - 动态权限申请：动态申请通知、存储、日历等权限，确保用户隐私安全。
  - 权限拒绝处理：在权限被拒绝时，提供友好的提示和降级方案，确保功能可用性。
- 用户认证：
  - 使用国内云服务（如阿里云、腾讯云）的用户认证功能，确保用户数据的安全性。
  - 支持多因素认证（如短信验证码、邮箱验证码），提升账户安全性。
3.3 兼容性需求
- 设备兼容：支持Android和iOS主流设备。
- 系统版本：支持Android 8.0及以上，iOS 12及以上。
